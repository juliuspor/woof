# woof artwork

The canonical application artwork is `boxer-master-1024.png`, a 1024 × 1024 RGBA boxer head with transparency.

Derived files:

- `woof-app.iconset` contains the standard macOS icon sizes.
- `woof.icns` is the application icon bundle.
- `woof-menubar-Template.png` and `woof-menubar-Template@2x.png` are monochrome menu-bar templates rendered from `assets/woof-menubar.svg`.
- `boxer-transparent-1024.png` and `boxer-chroma-1024.png` retain the prepared source variants.

Run `node scripts/build-icons.mjs` to reproduce the iconset, application icon, menu-bar assets, and staged application copies.
